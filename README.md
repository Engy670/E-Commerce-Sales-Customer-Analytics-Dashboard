# 📊 E-Commerce Sales & Customer Analytics Dashboard

An interactive end-to-end data analytics project built using **Microsoft Excel** to analyze sales performance, customer distribution, seller activities, and payment trends for an e-commerce platform (Olist Dataset).

> 🌟 **Note:** This project marks my final hands-on dashboard built in Microsoft Excel as I officially transition to advanced Power BI analytics and data modeling under the guidance of Instructor Mohamed!

---

## 📌 Executive Summary & Key Metrics

- **Total Revenue:** $13.59M generated across **99.44K** completed orders[cite: 1]
- **Average Order Value (AOV):** $136.7[cite: 1]
- **Freight Costs:** $2.25M in total shipping charges[cite: 1]
- **Top Location:** **São Paulo (SP)** leads with **54%** of total revenue (**40.3K+** orders)[cite: 2]
- **Top Category:** **Health & Beauty** ($1.25M), followed by **Watches & Gifts** ($1.2M)[cite: 3]
- **Payment Insights:** **Credit Cards** dominate with **75%–78%** of total payment volume, followed by **Boleto** at **19%**[cite: 4]

## 🛠️️ Features & Methodology

- **Data Cleaning & Preparation:** Structured raw relational tables, calculated missing metrics, and optimized dataset formatting.
- **Pivot Tables & Advanced Calculations:** Summarized multi-variable correlations (such as order installments vs. AOV and regional revenue distribution).
- **Interactive UI/UX Design:** Built a dark-themed custom dashboard with interactive category and state slicers for efficient data filtering.
